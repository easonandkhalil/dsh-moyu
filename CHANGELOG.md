# Changelog

## 0.1.0

First release.

- Side panel shaped like a CI build log: tab bar, two log panes, a worker-pool grid, a status bar.
- 56×14 snake in the grid; score shows as `✓ N passed`, best score as `concurrency peak N`.
- Three views: full, compact (grid only), camouflage (log only), on `Ctrl+Alt+L` / `Ctrl+Alt+H`.
- Panel is draggable by its tab bar and closed with `×`; position and view mode persist.
- Board freezes when the window is unfocused or the caret is in a text field.
